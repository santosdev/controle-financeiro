# 💰 Gestão Financeira Web

Sistema web de gestão financeira desenvolvido com Java, Spring Boot e MySQL, com o objetivo de facilitar o controle de receitas, despesas e movimentações financeiras.

## 🎯 Objetivo

Desenvolver uma aplicação web que permita organizar informações financeiras, acompanhar entradas e saídas de dinheiro e visualizar indicadores para auxiliar no planejamento financeiro.

## ⚙️ Funcionalidades

- Cadastro de receitas.
- Cadastro de despesas.
- Listagem de movimentações financeiras.
- Edição e exclusão de registros.
- Organização por categorias.
- Filtros por período e categoria.
- Visualização do saldo disponível.
- Dashboard com indicadores financeiros.
- Gráficos de receitas e despesas.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Finalidade |
|---|---|
| Java 21 | Lógica da aplicação |
| Spring Boot | Desenvolvimento do backend |
| Spring Data JPA | Persistência de dados |
| MySQL | Banco de dados |
| HTML5 | Estrutura das páginas |
| CSS3 | Estilização |
| JavaScript | Interatividade |
| Maven | Gerenciamento de dependências |
| Git e GitHub | Versionamento |

## 📊 Dashboard

O sistema contará com um painel financeiro para apresentar:

- Saldo total.
- Total de receitas.
- Total de despesas.
- Evolução financeira mensal.
- Despesas por categoria.
- Histórico de movimentações.
